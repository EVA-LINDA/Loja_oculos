# Loja_óculos

Página de uma loja de óculos com catálogo de produtos.

## Tecnologias
- React (com Vite)
- Node.js + Express (back-end / API de produtos)
- CSS

## Como rodar
npm install
npm run server   # back-end na porta 3001
npm run dev      # front-end na porta 5173
